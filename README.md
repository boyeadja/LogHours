# Hours Tracker

**Option 1: ZIP Download**
1. Click the "<> Code" button and select "Download ZIP"
2. Double-click the downloaded ZIP file to extract it
3. Open the extracted folder
4. Double-click "index.html"

**Option 2: Terminal**
1. Open Terminal
2. Run: `git clone https://github.com/boyeadja/LogHours`
3. Run: `cd logHours`
4. Run: `open index.html`
